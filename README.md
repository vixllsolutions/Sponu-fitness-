# SPONU Fitness Solution website

A responsive static website for SPONU Fitness Solution in Hosakerehalli, Bengaluru. It uses plain HTML, CSS and JavaScript and does not require a build step, framework or package installation.

## Files

- `index.html` — page content and semantic structure
- `style.css` — responsive layout, colours, hover states and reveal animations
- `script.js` — mobile navigation, smooth reveal-on-scroll, image viewer and current footer year
- `assets/media/` — supplied gym photos and SPONU Fitness Solution banner/logo
- `assets/reviews/` — supplied Google review screenshots displayed as images

## Preview locally

Open `index.html` in a modern browser. All internal images use relative paths. An internet connection is only needed for the optional Google Fonts request and external Google Maps link; fallback system fonts are included.

## Publish with GitHub Pages

1. Extract the ZIP.
2. Upload the contents of the `sponu_fitness_solution_website` folder to the root of your GitHub repository. Keep `index.html`, `style.css`, `script.js`, and `assets/` together.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose your main branch and `/ (root)`, then save.
5. Open the published Pages URL when GitHub reports the deployment is ready.
